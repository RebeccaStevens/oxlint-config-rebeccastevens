## Installation

```sh
pnpm add -D  \
  oxlint \
  @rebeccastevens/oxlint-config
```

```sh
pnpm dlx install-peerdeps @rebeccastevens/oxlint-config --dev -o -Y
```

Note: This project doesn't strictly follow semantic versioning so be sure to pin the version you are using.
